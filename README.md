# VU1FRA // SHADOW PROTOCOL

Кинематографичный 2D стелс-платформер в горизонтальной ориентации (Landscape-only PWA) о кибер-синоби **VU1FRA** из тайного ордена «Закон Тени» в туманном мегаполисе Нео-Эдо.

## Особенности
- **Чистый стелс без боёв**: наблюдение за маршрутами, игра света и глубоких теней, укрытия на переднем плане (`CoverSpot`), способность «Растворение в тени» (`Shadow-Dissolve`) и бесшумное нелетальное усыпление со спины.
- **Плавная векторная графика (Canvas 2D)**: силуэтный арт-дирекшн без пикселизации, 12-костный риг героя с аналитической 2-костной инверсной кинематикой (IK) ног и физикой шарфа на цепочке Верле (15 сегментов), предзапечённые слои параллакса, объёмный туман и карта освещения половинного разрешения.
- **Пять обучающих головоломок по ИБ (Глава I «Тихая крыша»)**:
  1. **Терминал A (`phishing_inspector`)** — анализ фишингового письма (подмена домена `.example`, искусственная срочность, несовпадение текста ссылки и реального `href`).
  2. **Терминал B (`password_lab`)** — уязвимость словарных паролей, сборка парольной фразы и декодирование Base64.
  3. **Терминал C (`log_forensics`)** — криминалистика серверных логов (`Brute-force`, ночной доступ, `Impossible Travel`).
  4. **Терминал D (`virtual_terminal`)** — виртуальная консоль с кнопками-командами (`whoami`, `ls`, `cat`, `grep`) без вызова экранной клавиатуры ОС.
  5. **Терминал E (`osint_scam`)** — перехват звонка «службы безопасности» и разбор утечки личных данных из открытого профиля соцсети (`OSINT`).
- Каждая головоломка завершается памяткой **«Как защититься в жизни»** и открывает карточку в **«Кодексе Тени»**.

## Как запустить
1. Установка и запуск локального сервера разработки:
   ```bash
   npm install
   npm run dev
   ```
2. Запуск автоматических модульных тестов движка и валидатора уровней:
   ```bash
   npx --yes tsx --test src/debug/engine.test.ts
   ```
3. Режимы проверки и отладки:
   - `?gallery=1` (или 5 нажатий на номер версии в правом нижнем углу меню) — интерактивная Галерея (все 14 анимаций героя с ползунком угла света, враги с индикатором подозрения, слои параллакса и тумана, все 9 кадров комиксов и все 5 головоломок).
   - `?debug=1` — панель разработчика (FPS, хитбоксы, режим Бога, пропуск головоломки, телепорт к выходу).
   - `?autostart=1` — мгновенный вход в игровой процесс Главы I.

## Как добавить новую главу (в 5 шагов без правок движка)
1. Создайте папку `/src/content/chapters/ch0X_name/`.
2. Опишите уровни (`levels/*.js`), головоломки (`puzzles/*.js`), комиксы (`comics/*.js`) и строки (`strings.ru.js`).
3. Соберите объект главы в `/src/content/chapters/ch0X_name/chapter.js`.
4. Импортируйте и добавьте главу одной строкой в массив `CHAPTER_REGISTRY` в `/src/content/registry.js`.
5. Запустите `LevelValidator` (`npx --yes tsx --test src/debug/engine.test.ts`) для автоматической проверки геометрии и прыжков.
